# TextHitKitDemo

TextHitKit 的交互测试 Demo，用于检查文本点击匹配、排版对齐、换行截断和规则切换。

## 依赖

项目通过 CocoaPods 以本地路径依赖引入 `TextHitKit`，并使用 SnapKit 布局：

```ruby
pod 'TextHitKit', :path => './TextHitKit'
pod 'SnapKit'
```

安装依赖后使用工作区打开工程：

```bash
pod install
open TextHitKitDemo.xcworkspace
```
